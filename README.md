# Проверка АВР — площадки Пром-1 и Пром-2

Интерактивные планы площадок: корпуса, инкубатории и ДГУ, дороги и ограждения. Каждый объект окрашен по состоянию проверки АВР:

- **зелёный** — акт проверки прикреплён и действует (45 дней со дня проверки, день проверки — первый; администратор может задать объекту свой срок от 10 до 45 дней);
- **зелёный с оранжевой рамкой** — до конца срока осталось 7 дней или меньше;
- **красный в полоску** — акта нет или срок истёк, здание ждёт новый акт;
- **серый** — контроль АВР выключен администратором (например, корпус пустой) или ещё не включён (ДГУ).

Нажмите на здание → «Прикрепить акт проверки» → сфотографируйте акт (можно с телефона, несколько страниц) → укажите дату проверки и выберите, кто проверял → «Загрузить на Google Диск». Здание сразу станет зелёным, а когда срок акта закончится, само снова станет красным.

Фото актов хранятся на **Google Диске**: «АВР — акты проверки» → «Пром-1» → «Корпус 12». Журнал всех актов ведётся в **Google Таблице** на листе «Журнал».

## Что в репозитории

| Файл | Зачем |
|---|---|
| `index.html` | сама страница; данных площадок и настроек в ней нет |
| `config.js` | настройки: адрес скрипта, срок акта, список площадок |
| `sites/p1.js`, `sites/p2.js` | планы площадок Пром-1 и Пром-2 |
| `apps-script/Code.gs` | копия скрипта Google: фото на Диск, журнал, коды доступа |
| `README.md` | эта инструкция |

Пока в `config.js` не указан адрес скрипта, страница работает в **демо-режиме**: акты примерные, загрузки никуда не сохраняются. Так можно посмотреть, как всё устроено, просто открыв `index.html` в браузере.

## Коды доступа

| Код | Что открывает |
|---|---|
| код Пром-1 | только площадку Пром-1: просмотр, загрузка и удаление актов |
| код Пром-2 | только площадку Пром-2 |
| код администратора | все площадки, обзор «Все площадки», включение и выключение контроля, срок акта по объекту |

Коды хранятся в Google Таблице на листе «Доступ», в файлы сайта их не вписывайте. Страница запоминает код в браузере; сменить его можно по ссылке «Сменить код доступа» внизу страницы.

## Контроль АВР и срок акта по объектам (для администратора)

Войдите с кодом администратора — у вкладок появится метка «Администратор». Откройте здание или ДГУ: в карточке есть блок управления (его видит только администратор).

- **Выключить контроль** — например, корпус пустой между посадками. Впишите причину и нажмите «Выключить». Здание станет серым и не будет считаться в сводке и в списке «Нужен акт». Акты к нему прикреплять можно.
- **Включить контроль** — здание снова окрасится по сроку последнего акта. Если акт за это время истёк, оно станет красным.
- **Срок действия акта** — впишите число от 10 до 45 и нажмите «Сохранить» (или Enter). Срок сразу пересчитывается по последнему акту: при более коротком сроке объект может стать оранжевым или красным. Чтобы вернуть общий срок, впишите 45. Свой срок видят все: в карточке объекта — «срок для объекта — N дней».

Каждое изменение записывается строкой на лист «Контроль» Google Таблицы: площадка, объект, вкл/выкл, когда, кто, причина, срок. Контроль и срок меняются независимо: у каждого действует последняя заполненная ячейка по объекту. Строку можно вписать и вручную: в столбце «Контроль» — `вкл` или `выкл`, в столбце G «Срок, дней» — число от 10 до 45 (`по умолч.` — вернуть общий срок).

**ДГУ** нанесены на планы и названы по подстанции, у которой стоят: «ДГУ ТП-43», «ДГУ КТПБ-90», «ДГУ зд. 66». Пока контроль по ним выключен — они серые. Когда начнёте делать акты по ДГУ, включите контроль в карточке каждой ДГУ.

## Обновление с версии 2.0 (если уже выложили)

1. Apps Script: замените весь код на `apps-script/Code.gs` → **Сохранить** → выберите **setup** → **Выполнить** (появится лист «Контроль» со столбцом G «Срок, дней») → **Развертывание → Управление развертываниями** → карандаш → **Новая версия** → **Развернуть**.
2. GitHub: **Add file → Upload files** → `index.html`, `README.md`, папки `sites` и `apps-script` → **Commit changes**. `config.js` не трогайте.
3. Откройте сайт и нажмите Ctrl + F5.

## Обновление с версии 1

Делайте по порядку: сначала скрипт Google, потом GitHub. Пока шаг 2 не сделан, старая страница продолжает работать с кодом Пром-1.

### Шаг 1. Google: новый скрипт (около 10 минут)

1. Откройте Google Таблицу с журналом актов → в меню **Расширения → Apps Script**.
2. В файле `Code.gs` выделите всё (Ctrl+A), удалите и вставьте содержимое файла `apps-script/Code.gs` из этого репозитория. Нажмите **Сохранить** (Ctrl+S).
3. Вверху редактора выберите функцию **setup** и нажмите **Выполнить**. Если Google попросит разрешение — разрешите, как при первой установке.
   В таблице появятся листы «Доступ», «Проверяющие» и «Контроль», в журнале — столбец J «Площадка». Старые записи не меняются, они относятся к Пром-1.
4. Лист **«Доступ»**, столбец «Код доступа»:
   - строка `p1` (Пром-1) — впишите **прежний код**, которым пользовались в версии 1. Тогда браузеры, где он сохранён, продолжат работать;
   - строка `p2` (Пром-2) — новый код для Пром-2;
   - строка `admin` (Администратор) — код администратора.

   Коды не короче 8 символов и разные для каждой строки.
5. Лист **«Проверяющие»**: в столбце A «ФИО» — по одному человеку в строке. Столбец B «Площадка» оставьте пустым, если человек проверяет на всех площадках, или впишите `Пром-1` / `Пром-2`.
6. **Развертывание → Управление развертываниями** → значок карандаша → «Версия»: **Новая версия** → **Развернуть**. Адрес `/exec` не меняется.

### Шаг 2. GitHub: новая страница

1. В репозитории откройте текущий `index.html` и найдите в блоке **НАСТРОЙКИ** строку `SCRIPT_URL: 'https://script.google.com/macros/s/…/exec'`. Скопируйте адрес между кавычками.
2. **Add file → Upload files** → перетащите из папки с новой версией всё сразу: `index.html`, `config.js`, `README.md`, папки `sites` и `apps-script` → **Commit changes**. Файлы с такими же именами заменятся.
3. Откройте `config.js` → значок карандаша (**Edit**) → вставьте адрес в строку `SCRIPT_URL: '',` между кавычками → **Commit changes**.
4. Удалите `satellite.jpg`: откройте файл → меню «…» → **Delete file** → **Commit changes**. Снимки со спутника больше не используются, а в публичном репозитории их видно всем.
5. Через 1–2 минуты откройте сайт и обновите страницу с очисткой кэша: **Ctrl + F5** (на Mac: Cmd + Shift + R). Введите код.

## Новая установка (если версии 1 не было)

1. Откройте [sheets.new](https://sheets.new) — создастся Google Таблица. Назовите её, например, «АВР — журнал актов».
2. **Расширения → Apps Script** → удалите всё в `Code.gs` → вставьте `apps-script/Code.gs` → **Сохранить**.
3. Выберите функцию **setup** → **Выполнить** → выберите свой аккаунт → «Дополнительные настройки» → «Перейти на страницу проекта (небезопасно)» → «Разрешить». Это обычное предупреждение для собственных скриптов.
4. Заполните листы «Доступ» и «Проверяющие», как в шаге 1 выше.
5. **Начать развертывание → Новое развертывание** → значок шестерёнки → **Веб-приложение**: «Запуск от имени» — **я**; «У кого есть доступ» — **все** → **Начать развертывание** → скопируйте URL веб-приложения (заканчивается на `/exec`).
6. На [github.com](https://github.com): **New repository** → **Add file → Upload files** → все файлы и папки этого репозитория → **Commit changes**.
7. В `config.js` впишите адрес скрипта в `SCRIPT_URL` → **Commit changes**.
8. **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → **Save**. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

## Как добавить площадку

1. Claude готовит файл площадки `sites/p3.js` по схеме и списку зданий.
2. GitHub: откройте папку `sites` → **Add file → Upload files** → перетащите `p3.js` → **Commit changes**.
3. В `config.js` добавьте код в список: `SITES: ['p1', 'p2', 'p3']` → **Commit changes**.
4. Google Таблица, лист «Доступ»: новая строка `p3` | `Пром-3` | код доступа. Развертывание обновлять не нужно.

`index.html` при этом не меняется.

## Ссылки на площадку и здание

- `…/#all` — обзор «Все площадки» (для кода администратора);
- `…/#p2` — сразу площадка Пром-2;
- `…/#p2-54` — карточка корпуса 54 на Пром-2, `…/#p1-ДГУ ТП-43` — карточка ДГУ ТП-43 на Пром-1. Такую ссылку можно напечатать QR-кодом на шкафу АВР.

## Настройки в config.js

| Настройка | По умолчанию | Что значит |
|---|---|---|
| `SCRIPT_URL` | пусто | адрес веб-приложения Apps Script (`…/exec`); пусто — демо-режим |
| `VALID_DAYS` | `45` | сколько дней действует акт, считая со дня проверки; отдельным объектам администратор задаёт свой срок (10–45) в карточке |
| `WARN_DAYS` | `7` | за сколько дней до конца срока обводить здание оранжевой рамкой; `0` — не обводить |
| `REFRESH_MIN` | `3` | как часто страница обновляет данные, в минутах |
| `SITES` | `['p1', 'p2']` | площадки в порядке вкладок |

## Частые вопросы

**Акт загрузили не в то здание.** Откройте здание → «История актов» → «Удалить». Запись помечается удалённой в журнале (столбец «Удалён»), фото остаются на Диске. Чтобы вернуть запись, очистите эту ячейку в таблице.

**Как внести старые акты?** Прямо в таблицу, лист «Журнал», новой строкой: «Корпус» — номер (для ДГУ — название как на плане, например `ДГУ ТП-43`), «Дата проверки» — `2026-10-13` или `13.10.2026`, «Кто проверял», в столбце J «Площадка» — `p2` или `Пром-2`. Пустая «Площадка» означает Пром-1. Остальные столбцы можно оставить пустыми.

**Как сменить код доступа?** Поменяйте код на листе «Доступ» — он действует сразу, развертывание обновлять не нужно. Если сотрудник больше не должен иметь доступ к площадке — смените её код.

**Изменил скрипт, а ничего не поменялось.** После любой правки `Code.gs` выпустите новую версию развертывания: **Развертывание → Управление развертываниями** → карандаш → «Версия: новая версия» → «Развернуть».

**Страница пишет «Нет связи со скриптом Google».** Проверьте, что адрес в `config.js` заканчивается на `/exec` и что при развертывании выбран доступ «Все».

**Страница пишет, что коды не заданы.** Заполните столбец «Код доступа» на листе «Доступ».

**Изменения на сайте не видны.** GitHub Pages может несколько минут отдавать старые файлы. Обновите страницу с очисткой кэша: Ctrl + F5.

**Что видно всем.** Бесплатный GitHub Pages работает с публичными репозиториями: код страницы и планы площадок может открыть любой, у кого есть ссылка. Акты, журнал, ФИО и коды доступа остаются в вашем Google и открываются только с кодом.

**Ограничения.** До 6 файлов в одном акте, до 15 МБ каждый. Фото перед загрузкой уменьшаются до 2000 пикселей по длинной стороне — текст акта остаётся читаемым, а загрузка с телефона идёт быстро.
